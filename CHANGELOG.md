# Changelog

## 1.0.0 — Initial public release (8 November 2026)

- Added a dedicated FTB Quests inventory-selection interface.
- Select individual eligible inventory slots and quantities rather than consuming items automatically.
- Added green selected-slot outlines and darkened ineligible items.
- Added View Eligible Items and FTB Quests theme integration.
- Uses standard FTB Quests item and filter matching, including applicable NBT conditions.
- Validates submission packets and inventory items server-side.
- Supports singleplayer and multiplayer.

### Source recovery (14 November 2026)

- Recovered Java implementation and original resources from the published production JAR.
- Preserved the binary's internal version `1.0.0-rc.1`; CurseForge presents it as release 1.0.0.
- Added build tooling, documentation, and All Rights Reserved source licensing.
- No changes made to the published CurseForge JAR.
